# Rejected

Don't install these. Reason and the alternative to use instead.

## korotovsky/slack-mcp-server
- Repo: https://github.com/korotovsky/slack-mcp-server
- **Why:** Advertises "stealth mode" using browser session tokens (`xoxc`/`xoxd`) to bypass workspace app approval. Gets around Slack's terms and admin controls.
- **Use instead:** [[Slack]] (official)
- Rejected: 2026-11-06

## semgrep/mcp (standalone)
- Repo: https://github.com/semgrep/mcp
- **Why:** Deprecated: README says it moved into the main `semgrep` binary. No updates since Oct 2025.
- **Use instead:** [[Semgrep]] plugin
- Rejected: 2026-11-06

## makenotion/notion-mcp-server
- Repo: https://github.com/makenotion/notion-mcp-server
- **Why:** Notion says it's no longer maintained or supported.
- **Use instead:** [[Notion]] (remote MCP plugin)
- Rejected: 2026-11-06
