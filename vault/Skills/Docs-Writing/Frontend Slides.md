# Frontend Slides

Animated HTML slide decks from an idea or a .pptx.

## What it does
- Zero-dependency HTML presentations with style presets; can convert PowerPoint to web.

## Install
```
/plugin marketplace add https://github.com/zarazhangrui/frontend-slides
/plugin install frontend-slides@frontend-slides
```
Scan first: `skillspector scan https://github.com/zarazhangrui/frontend-slides --no-llm`

## Usage
- *"Make a 10-slide pitch deck about Attune."*
