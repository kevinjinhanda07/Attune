# Find Skills

Search and install skills from the open skills directory (skills.sh).

## What it does
- Uses the `npx skills` CLI: `find`, `add`, `update`.

## Install
```
npx skills add vercel-labs/skills --skill find-skills
```
Scan first: `skillspector scan https://github.com/vercel-labs/skills --no-llm`

## Usage
- *"Find a skill for making Roblox UI."*

## Caveats/risks
- **Installs third-party skills with no vetting.** Always run [[SkillSpector]] on a result before adding it, and use this vault's checklist.

**Verdict: CAUTION** (2026-11-06). Read SKILL.md: instructions only. Caution is about what it installs, not the skill itself.
