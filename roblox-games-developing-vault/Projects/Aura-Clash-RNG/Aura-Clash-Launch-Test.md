# Month-1 launch & market test
Up: [[MOC-Aura-Clash]] · Skills: `roblox-thumbnail-icon-title`, `roblox-social-virality`, `roblox-liveops-events`

## Goal
Prove players **stay**, then grow. CCU follows retention.

| Metric | Target before scaling |
|---|---|
| D1 (next-day return) | 12–15%+ |
| Avg session | 12+ min |
| Thumbnail CTR / qPTR | near similar games |
| CCU milestones | 50 → 200 → 1,000 |

## Week 5 – soft launch
- [ ] Maturity questionnaire (aim Mild) · [[Launch-Checklist]]
- [ ] Icon + 3–5 thumbnails (rare roll, aura storm, clash win) – all active for personalization
- [ ] Roblox group + in-game group reward
- [ ] Ads Manager test: ~$50–100 over 3–5 days. Note cost per play + D1 of those players.
- [ ] 1 short clip per day (TikTok / YouTube Shorts)

## Week 6
- [ ] Read funnel → fix the biggest drop
- [ ] Real PvP Clash matchmaking live

## Week 7
- [ ] Announce weekly update day/time; first event (new aura + limited fighter)
- [ ] DM 20 small YouTubers (1K–50K subs): code + free private server + early access

## Week 8 – decision gate
| Result | Do |
|---|---|
| D1 ≥ 12% and session ≥ 12 min | scale ads slowly, weekly updates, add rebirth then trading |
| Good session, weak D1 | add return hooks: daily streak, timed restocks, offline cap reminders |
| Weak both | change theme/twist, re-test with new thumbnails before more ads |
| Good retention, low spend | improve shop value + timing, not prices |
