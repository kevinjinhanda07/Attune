# Moon Animator
Up: [[MOC-Tools]] · Guide: [[Animation-Guide]]

**Verdict: ⚠️ CAUTION** – excellent, widely used paid Studio plugin. Caution: buy only the **official listing** (fakes exist), and it's closed source.

Use for cutscenes, camera work, multi-rig scenes, easing curves. For simple rig anims the built-in Animation Editor is enough.
