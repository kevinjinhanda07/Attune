# Viral Roblox Game Concept

## Rules
- Original names, characters, art direction, maps. Shared genre mechanics are fine; copying a specific game is not. If asked to clone, propose an original remix and explain the difference.
- Aim for Minimal/Mild maturity unless the user targets older players.

## Process
1. **Inputs**: team size, skills (code/art), time budget, target age, genres they like.
2. **Trend scan**: list the current proven loops (e.g. idle grow/collect, collect-and-raid tycoon, co-op survival run, anomaly/spot-the-difference horror, short-round PvP, social deduction, roleplay). Ask the user for current chart observations if you can't browse.
3. **Generate 10 concepts**: each = proven loop × fresh theme × one twist. Formula: *"[Verb] [things] to [goal], but [twist]"*.
4. **Score** each 1–5 (table below). Weighted total /100.
5. **Pick top 2**, write a 1-page pitch each: hook, 30-s loop, first 60 s, rarity ladder, social hook, clip moment, monetization, weekly-update plan, icon idea.
6. **Scope check** vs team/time: MVP ≤ 4 weeks for a solo dev.

## Scoring rubric
| Criterion | Weight | 5 = |
|---|---|---|
| Loop readable in 3 s from a screenshot | 15 | a kid explains it instantly |
| Collection/rarity depth | 10 | endless tiers + modifiers |
| Social hook | 15 | other players create stories (raid, co-op, trade) |
| Clip-ability | 15 | obvious 10-s TikTok moment |
| Mobile-first | 10 | one-thumb, low-end friendly |
| Live-ops fuel | 10 | new items/zones weekly is cheap |
| Icon/title strength | 10 | one bold image + clear title |
| Originality | 10 | fresh theme/twist, not a reskin |
| Scope fit | 5 | MVP within budget |

## Output
Table of 10 scored concepts → 2 pitches → next step: link to `roblox-core-loop-progression` and the vault's Hit-Game-Blueprint.
