# Thumbnail, Icon & Title

## Icon (512×512, read at ~64 px)
- One subject (original character/object), huge, centered, slight angle.
- High contrast, saturated, simple background gradient; thick outline/rim light.
- Emotion on faces (surprise, joy, fear).
- Max 1–3 words of text, if any. Test by shrinking to 64 px on a phone.

## Thumbnails (16:9, 1920×1080, keep file small)
- Show the **loop and the payoff**: the rare item, the huge number, the scary moment, friends together.
- Foreground subject, mid action, background context. Rule of thirds, safe margins (UI overlays crop).
- Make 3–5 different angles (rarity, social, event, humor) and keep several active: Roblox's thumbnail personalization serves each audience the best performer by qPTR (Creator Hub → place → Thumbnails). Experiment APIs exist on Open Cloud (2026).
- Must reflect real gameplay (policy: no misleading thumbnails, no Roblox logos/fake UI badges, no copyrighted characters).

## Title
- Formula: `[Verb] a/an [Noun]` or `[Number] [Noun] in the [Place]` or `[Noun] [Genre]`. 2–5 words, clear goal, unique enough to search.
- Optional honest tags: `[UPDATE]`, `[EVENT]`, an emoji. Don't stack many; remove when stale.
- Avoid using other games' names or trademarked terms.

## Description
- Line 1: hook + loop in one sentence.
- Then: features bullets, update day/time, group/social rules (allowed links only).

## Process
1. Brief: core fantasy, best moment, target age.
2. Sketch 6 icon thumbnails at tiny size; pick 2.
3. Render in Studio (high graphics, posed characters) or Blender; paint over.
4. Upload 3–5 thumbnails + icon; watch qPTR/CTR for 1–2 weeks.
5. Refresh art each event/season.

## Metrics
- Impressions → plays = CTR; qPTR = plays that stayed meaningfully. High CTR + low qPTR → art overpromises; fix art or onboarding.
