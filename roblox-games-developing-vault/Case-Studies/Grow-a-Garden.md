# Grow a Garden
Up: [[MOC-Case-Studies]] · Patterns: [[Hit-Game-Patterns]]

> Mechanics and lessons only. Use them as inspiration for **original** designs.

- **Status:** 2025's biggest hit; ~22.3M peak CCU (Aug 23 2025, Admin War); People's Choice + Most CCU awards
- **Genre:** Idle farming / collection
- **Core loop:** Buy seeds from a restocking shop → plant → crops grow in real time (incl. offline) → weather mutations multiply value → sell → buy rarer seeds/pets
- **Session:** Many short check-ins per day
- **Social:** Visiting/trading, shared weather events across the server, admin events
- **Monetization:** Seed/gear packs, restock skips, pets (check current)
- **Update cadence:** Weekly Saturday updates; update day CCU far above normal days; 'admin abuse' live events before updates
- **Why it spread:** Cozy theme for all ages; shop restock timers create appointment play; huge YouTube/TikTok coverage of rare mutations. Note: analysts alleged some bot inflation

## Lessons
- Offline progress + timed restocks = daily habit
- server-wide random events make everyone talk at once
- fixed weekly update day trains players to return
