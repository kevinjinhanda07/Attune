# RIVALS
Up: [[MOC-Case-Studies]] · Patterns: [[Hit-Game-Patterns]]

> Mechanics and lessons only. Use them as inspiration for **original** designs.

- **Status:** Top competitive shooter; ~220K+ CCU, top earner (2026)
- **Genre:** PvP arena shooter
- **Core loop:** Queue → short 1v1/team duels → earn keys/currency → unlock weapons/skins → ranked
- **Session:** 2–5 min matches, many per session
- **Social:** Duels with friends, ranked ladder, spectating
- **Monetization:** Cosmetic skins/wraps, cases (odds shown)
- **Update cadence:** Seasonal content, weapon balance patches
- **Why it spread:** Tight gunplay that feels 'real' on mobile + PC; skill clips

## Lessons
- Cosmetic-only monetization works in PvP
- short matches + ranked = 'one more'
