# Blox Fruits
Up: [[MOC-Case-Studies]] · Patterns: [[Hit-Game-Patterns]]

> Mechanics and lessons only. Use them as inspiration for **original** designs.

- **Status:** Evergreen; ~58B visits (Jan 2026)
- **Genre:** Action RPG / grind
- **Core loop:** Fight NPCs → level → find/eat rare powers (fruits) → seas/zones → bosses/raids → PvP
- **Session:** Long sessions
- **Social:** Trading, crews, PvP, bounties
- **Monetization:** Permanent power passes, power items (debated pay-to-win)
- **Update cadence:** Big infrequent updates with long hype cycles
- **Why it spread:** Anime-power fantasy + rarity + trading = endless YouTube content

## Lessons
- Rarity + trading creates an economy that sustains years
- big updates need hype countdowns
