# Steal An Egg
Up: [[MOC-Case-Studies]] · Patterns: [[Hit-Game-Patterns]]

> Mechanics and lessons only. Use them as inspiration for **original** designs.

- **Status:** 2026 breakout (Jul 2026); #1 by concurrency in Oct 2026 (~1–1.4M avg CCU per trackers; ~2.2M peak Aug 2026)
- **Genre:** Collect / steal tycoon
- **Core loop:** Grab eggs → hatch pets → pets earn cash → upgrade base & speed (treadmill) → steal better eggs from other bases
- **Session:** 5–20 min, idle income between
- **Social:** Stealing from others = constant PvP drama; friends raid together; Minimal rating = all ages
- **Monetization:** Speed/luck boosts, pet eggs, base protection (check current)
- **Update cadence:** Frequent new eggs/pets
- **Why it spread:** Took the proven 'steal a ___' loop (see [[Steal-a-Brainrot]]) and swapped the theme to cute egg/pet collecting; Minimal maturity label widened audience

## Lessons
- Remix a proven loop with a fresh, broad theme
- physical stealing creates stories
- Minimal rating = biggest audience
