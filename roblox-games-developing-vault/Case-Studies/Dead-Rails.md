# Dead Rails
Up: [[MOC-Case-Studies]] · Patterns: [[Hit-Game-Patterns]]

> Mechanics and lessons only. Use them as inspiration for **original** designs.

- **Status:** 2025 hit; Best Use of Tech + Best Strategy awards
- **Genre:** Co-op survival run
- **Core loop:** Drive a train across a dangerous frontier → stop to scavenge fuel/loot → defend at night → reach the end
- **Session:** ~30–60 min run
- **Social:** 4-player co-op roles, emergent stories
- **Monetization:** Classes, cosmetics (check current)
- **Update cadence:** Content updates & new classes
- **Why it spread:** Clear journey goal; dramatic co-op moments; strong tech/visuals

## Lessons
- A run with a destination gives structure
- resource pressure (fuel) forces teamwork
