# Animal Hospital
Up: [[MOC-Case-Studies]] · Patterns: [[Hit-Game-Patterns]]

> Mechanics and lessons only. Use them as inspiration for **original** designs.

- **Status:** 2026 horror breakout (May 2026); ~361K peak CCU (Aug 2026)
- **Genre:** Co-op anomaly horror
- **Core loop:** Night shift at a vet clinic → check in patients → spot anomalies and reject them → treat real patients → keep Sanity above zero → next shift
- **Session:** Shift-length rounds
- **Social:** Co-op spotting (‘is that one wrong?’), streamer reactions
- **Monetization:** Cosmetics/boosts (check current)
- **Update cadence:** ~2-week named updates (e.g. July 2026)
- **Why it spread:** 'Spot the anomaly' format is social and clip-friendly; cute theme + horror twist

## Lessons
- Observation puzzles + co-op = discussion
- cute/scary contrast
- accessibility options (strobe toggle) matter
