# Genre templates (make them yours)
Up: [[MOC-Design]]

| Genre | Loop | Original twist ideas |
|---|---|---|
| Simulator | collect → sell → upgrade → new zone → rebirth | collect sounds to compose songs; terraform a tiny planet |
| Obby | stage → checkpoint → harder stage | course reassembles every round from a kit |
| Tycoon | droppers → collect → buy next tier | run a monster hotel with guest needs |
| Tower defense | waves → earn → place/upgrade | towers are plants you grow between waves |
| Horror | calm → hint → threat → release | co-op lighthouse keepers, light is the resource |
| Roleplay | jobs → money → home/customize | small floating island town that players expand together |
| Arena | short rounds, few readable moves | gravity flips every 30 s |
