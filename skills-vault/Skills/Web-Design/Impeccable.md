# Impeccable

Design-director skill with 24 commands: audit, critique, polish, animate, bolder.

## What it does
- `/impeccable critique|polish|animate|typeset|colorize|bolder|quieter|overdrive…`
- Anti-pattern detection; live in-browser editing mode.

## Install
```
/plugin marketplace add pbakaus/impeccable
/plugin install impeccable@impeccable
```
