# Superdesign

Design drafts on an infinite canvas with several AI models.

## What it does
- Generate and compare UI directions, design systems, slides, graphics.

## Install
```
/plugin marketplace add superdesigndev/superdesign-skill
/plugin install superdesign@superdesign
```
Scan first: `skillspector scan https://github.com/superdesigndev/superdesign-skill --no-llm`

## Usage
- *"Explore 3 design directions for this landing page."*

## Caveats/risks
- Runs `npx --yes @superdesign/cli@latest` (unpinned) and sends your code/designs to Superdesign's cloud.
- Account and paid usage.

**Verdict: CAUTION** (2026-11-06). Read SKILL.md: clear instructions, but cloud service + auto-installed latest CLI.
