# UI UX Pro Max

Searchable style/palette/font-pairing database for UI decisions.

## What it does
- Styles, 192 palettes, 74 font pairings, UX rules, GSAP presets, queried by a local script.

## Install
```
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill
```
Scan first: `skillspector scan https://github.com/nextlevelbuilder/ui-ux-pro-max-skill --no-llm`

## Usage
- *"Pick a palette and font pairing for a fintech dashboard."*

## Caveats/risks
- Database-driven picks can feel template-y: use for starting points, then art-direct.

**Verdict: APPROVE** (2026-11-06). Read SKILL.md and scripts: local CSV search; links only to Pexels/Google Fonts.
