## Adding a new skill
1. **Scan with SkillSpector first:** `skillspector scan <repo URL> --no-llm`
2. Use the original repo, not a fork. Check the name on PyPI/npm isn't a different project.
3. Read every `SKILL.md`, plus install scripts, hooks (`hooks.json`) and `.mcp.json`.
4. Note what it installs, where your data goes, telemetry, and whether it changes global config.
5. Give a verdict: APPROVE / CAUTION / REJECT. Rejects go in [[Rejected]] with the reason.
6. Make `Skills/<Category>/<Name>.md` from an existing note; copy its SKILL.md files into `Skills/<Category>/<Name>/`.
7. Add it to its `Categories/` note and the table above. Remove it from [[Inbox]].
8. Install on my computer only after steps 1–5 pass. Then flip **Installed?** to yes.
9. Commit and push to the `skills-vault` branch.
